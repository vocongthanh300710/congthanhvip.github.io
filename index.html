TRIP01 — Lời giải

Hành trình quay về đỉnh 1 đúng T bước · Tổng phần thưởng lớn nhất
Đồ thị có hướng Ma trận max-plus Luỹ thừa nhanh O(N³ log T)

1. Đề bài

Cho đồ thị có hướng N đỉnh, M cung. Mỗi đỉnh i có trọng số phần thưởng c[i]. Mỗi cung tốn 1 đơn vị thời gian. Xuất phát tại đỉnh 1 lúc t=0, quay về đỉnh 1 đúng lúc T. Mỗi lần ghé đỉnh nhận c[i]. Tìm tổng phần thưởng lớn nhất, hoặc -1.

Ràng buộcGiá trị
N≤ 250
M≤ 1000
T≤ 10⁹
c[i]1 … 10⁴

2. Ý tưởng (theo lời giải thích của thầy)

💬 Trích lời thầy:
"Ta tận dụng việc không tồn tại ràng buộc về số lần ghé thăm mỗi đỉnh để xây dựng hẳn một ma trận biến đổi cố định:

M[u, v] = điểm thưởng lớn nhất để đi từ u đến v qua đúng 1 cạnh.
Suy ra:
M²[u, v] = điểm lớn nhất qua đúng 2 cạnh
…
Mk[u, v] = điểm lớn nhất qua đúng k cạnh.

Vậy để tính điểm lớn nhất để đi từ 1 đến tất cả các đỉnh sau đúng T cạnh, ta chỉ cần lấy V * MT,
với V[1] = 0, V[u] = -∞ với mọi u khác 1."

Ma trận biến đổi M

M[u][v] = c[v]   nếu có cung u → v
M[u][v] = -∞     nếu không có cung

Phép nhân max-plus

(X ⊗ Y)[i][j] = max_k ( X[i][k] + Y[k][j] )

Đáp án

ans = MT[1][1] + c[1]
Lưu ý về c[1]: Vì M[u][v] = c[v] chỉ cộng phần thưởng khi tới v, còn phần thưởng tại điểm xuất phát c[1] (t = 0) chưa được cộng. Vậy phải cộng thêm c[1] ở cuối.

Kiểm chứng Ví dụ 1

N=3, M=4, T=6, c = [5, 2, 8], cung: 1→2, 2→1, 2→3, 3→1.

Chu trình 1→2→3→1 dài 3 bước, điểm mỗi vòng = 2 + 8 + 5 = 15.

T = 6 = 3×2 → M⁶[1][1] = 30. Cộng c[1] = 5 → 35. ✓

3. Vì sao dùng nhân ma trận?

3.1. Bước đi = một phép biến đổi

Nhìn lại M[u][v] = c[v]: khi ở u bước sang v, phần thưởng cộng thêm đúng bằng M[u][v]. Vậy một bước đi = một lần áp dụng ma trận M.

3.2. Hai bước liên tiếp = M²

Đi từ u sang v qua 2 cạnh phải qua đỉnh trung gian k:

u → k → v

Điểm = M[u][k] + M[k][v]. Muốn tối ưu, thử mọi k:

M²[u][v] = max_k ( M[u][k] + M[k][v] )

Đây chính xác là công thức nhân max-plus:

(X ⊗ Y)[i][j] = max_k ( X[i][k] + Y[k][j] )

3.3. Quy nạp: k bước = Mᵏ

Mk[u][v] = điểm lớn nhất đi từ u đến v qua đúng k cạnh

3.4. Vì sao cần luỹ thừa nhanh?

T tới 10⁹. Nếu nhân tuần tự:

T × O(N³) ≈ 10⁹ × 250³ → quá lớn, không chạy nổi

Nhưng nhân ma trận kết hợp → dùng luỹ thừa nhị phân:

MT = Mb₀ ⊗ M2b₁ ⊗ M4b₂ ⊗ …

Chỉ tốn O(log T) phép nhân → O(N³ log T) ≈ 4.7 × 10⁸ phép.

4 lý do dùng nhân ma trận:
  1. T quá lớn để mô phỏng từng bước.
  2. Một bước đi biểu diễn thành phép áp dụng ma trận M.
  3. k bước liên tiếp = Mk, nhờ nhân max-plus.
  4. Tính kết hợp cho phép luỹ thừa nhanh → T = 10⁹ chỉ trong O(log T) phép nhân.

3.5. So sánh các cách tiếp cận

CáchPhức tạpVới T = 10⁹
DP từng bướcO(T · M)Quá chậm
Dijkstra / Bellman-FordKhông áp dụng đượcCần đúng T bước
Ma trận max-plus + luỹ thừa nhanhO(N³ log T)Chạy tốt

4. Code C++

#include<bits/stdc++.h>
#define ll long long
using namespace std;
const int N = 252;
const ll INF = 1e18;
int n, m;
ll t, c[N], a[N][N], b[N][N], d[N][N];
void mul(ll x[N][N], ll y[N][N], ll z[N][N]){
    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= n; j++){
            z[i][j] = -INF;
            for(int k = 1; k <= n; k++){
                if(x[i][k] != -INF && y[k][j] != -INF){
                    z[i][j] = max(z[i][j], x[i][k] + y[k][j]);
                }
            }
        }
    }
}
void init(){
    ios_base::sync_with_stdio(false);
    cin.tie(0); cout.tie(0);
    cin >> n >> m >> t;
    for(int i = 1; i <= n; i++) cin >> c[i];
    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= n; j++) a[i][j] = -INF;
    }
    for(int i = 1; i <= m; i++){
        int u, v; cin >> u >> v;
        a[u][v] = max(a[u][v], c[v]);
    }
}
void solve(){
    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= n; j++){
            b[i][j] = (i == j ? 0 : -INF);
        }
    }
    while(t > 0){
        if(t & 1){
            mul(b, a, d);
            for(int i = 1; i <= n; i++){
                for(int j = 1; j <= n; j++) b[i][j] = d[i][j];
            }
        }
        mul(a, a, d);
        for(int i = 1; i <= n; i++){
            for(int j = 1; j <= n; j++) a[i][j] = d[i][j];
        }
        t >>= 1;
    }
    if(b[1][1] == -INF) cout << -1;
    else cout << b[1][1] + c[1];
}
int main(){
    init();
    solve();
}

TRIP02 — Lời giải

TRIP02 — Lời giải

Hành trình có sự kiện đặc biệt · Cung có trọng số thời gian w
Đồ thị có hướng Ma trận 5n Sự kiện đặc biệt O((5n)³ log T)

1. Đề bài

Cho đồ thị có hướng N đỉnh, M cung. Mỗi đỉnh i có trọng số phần thưởng c[i]. Mỗi cung u → v tốn w[i] đơn vị thời gian (1 ≤ w ≤ 5). Xuất phát tại đỉnh 1 lúc t=0, quay về đỉnh 1 đúng lúc T.

Có k sự kiện đặc biệt (t, x, y): nếu ở đỉnh x đúng lúc t thì cộng thêm y. Nếu đang đi trên đường thì không nhận.

Tìm tổng phần thưởng lớn nhất, hoặc -1.

Ràng buộcGiá trị
N≤ 50
M≤ 550
K≤ 200
T≤ 10⁹
w[i]1 … 5
c[i]≤ 52525
y[i]≤ 10⁹

2. Ý tưởng

💬 Lời giải:
"Điểm khó nhất là T ≤ 10⁹, không thể chạy DP từng thời điểm. Nhưng trọng số thời gian của mỗi cạnh chỉ từ 1 đến 5, giúp ta xây dựng ma trận chuyển trạng thái kích thước nhỏ."

2.1. DP cơ bản (khi T nhỏ)

dp[t][v] = phần thưởng lớn nhất khi đến đỉnh v đúng thời điểm t
dp[0][1] = c[1]
Với mỗi cạnh u → v có thời gian w:
    dp[t + w][v] = max(dp[t + w][v], dp[t][u] + c[v])

2.2. Biến DP thành ma trận max-plus

Dùng nhân max-plus: C_ij = max_k (A_ik + B_kj).

2.3. Tại sao ma trận kích thước 5n?

Một cạnh có thể mất từ 1 đến 5 đơn vị thời gian. Vì vậy, để tính DP ở thời điểm tiếp theo, ta cần nhớ DP của 5 lớp thời gian gần nhất:

V_t = [dp[t], dp[t-1], dp[t-2], dp[t-3], dp[t-4]]T

Mỗi lớp có n phần tử → vector có 5n phần tử. Ta có V_{t+1} = M · V_t.

2.4. Ma trận M có hai phần

  • Phần chuyển trạng thái: Với cạnh u → v có trọng số w, cập nhật từ dp[t + 1 - w][u] sang dp[t+1][v], cộng phần thưởng c[v].
  • Phần dịch lớp: Chuyển các lớp dp[t], dp[t-1], … xuống vị trí tiếp theo trong vector.

2.5. Xử lý sự kiện đặc biệt

Khi đến đỉnh x đúng thời điểm t, được thêm y điểm. Gọi M_t là ma trận đặc biệt ở thời điểm t: mọi cạnh đi vào x đều được cộng thêm y.

V_t = M_t · V_{t-1}

Sắp xếp sự kiện theo thời gian. Giữa hai sự kiện, dùng luỹ thừa ma trận thường. Đúng tại thời điểm sự kiện, dùng ma trận đặc biệt.

2.6. Tối ưu luỹ thừa

Tiền xử lý P_i = M^(2^i) để mỗi khoảng thời gian chỉ cần O(log T) phép nhân vector.

3. Code C++

#include<bits/stdc++.h>
#define ll long long
using namespace std;
const int N = 52;
const int S = 250;
const int LOG = 30;
const ll NEG = -(1LL << 60);
int n, m, k, u[N * 12], v[N * 12], w[N * 12], cnt;
int sz;
ll T, c[N];
ll pw[LOG][S][S], tmp[S][S], dp[S], ndp[S];
struct tt{
    ll t, y;
    int x;
};
tt e[205];
bool cmp(tt a, tt b){
    return a.t < b.t;
}
void mul(int z){
    for(int i = 0; i < sz; i++){
        for(int j = 0; j < sz; j++){
            tmp[i][j] = NEG;
        }
    }
    for(int i = 0; i < sz; i++){
        for(int j = 0; j < sz; j++){
            if(pw[z][i][j] == NEG) continue;
            ll x = pw[z][i][j];
            for(int h = 0; h < sz; h++){
                if(pw[z][j][h] == NEG) continue;
                tmp[i][h] = max(tmp[i][h], x + pw[z][j][h]);
            }
        }
    }
    for(int i = 0; i < sz; i++){
        for(int j = 0; j < sz; j++){
            pw[z + 1][i][j] = tmp[i][j];
        }
    }
}
void apply(int z){
    for(int i = 0; i < sz; i++){
        ndp[i] = NEG;
        for(int j = 0; j < sz; j++){
            if(pw[z][i][j] == NEG || dp[j] == NEG) continue;
            ndp[i] = max(ndp[i], pw[z][i][j] + dp[j]);
        }
    }
    for(int i = 0; i < sz; i++) dp[i] = ndp[i];
}
void go(ll d){
    int bit = 0;
    while(d > 0){
        if(d & 1) apply(bit);
        d >>= 1;
        bit++;
    }
}
void step(int x, ll y){
    for(int i = 0; i < sz; i++) ndp[i] = NEG;
    for(int i = 1; i <= cnt; i++){
        int a = u[i], b = v[i], t = w[i];
        ll val = dp[(t - 1) * n + a];
        if(val == NEG) continue;
        val += c[b];
        if(b == x) val += y;
        ndp[b] = max(ndp[b], val);
    }
    for(int j = 1; j < 5; j++){
        for(int i = 0; i < n; i++){
            ndp[j * n + i] = dp[(j - 1) * n + i];
        }
    }
    for(int i = 0; i < sz; i++) dp[i] = ndp[i];
}
void init(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m >> T >> k;
    for(int i = 0; i < n; i++) cin >> c[i];
    cnt = m;
    for(int i = 1; i <= m; i++){
        cin >> u[i] >> v[i] >> w[i];
        u[i]--;
        v[i]--;
    }
    for(int i = 1; i <= k; i++){
        cin >> e[i].t >> e[i].x >> e[i].y;
        e[i].x--;
    }
    sort(e + 1, e + k + 1, cmp);
}
void solve(){
    sz = 5 * n;
    for(int i = 0; i < sz; i++){
        for(int j = 0; j < sz; j++){
            pw[0][i][j] = NEG;
        }
    }
    for(int i = 1; i <= m; i++){
        int a = u[i], b = v[i], t = w[i];
        pw[0][b][(t - 1) * n + a] = max(pw[0][b][(t - 1) * n + a], c[b]);
    }
    for(int j = 1; j < 5; j++){
        for(int i = 0; i < n; i++){
            pw[0][j * n + i][(j - 1) * n + i] = 0;
        }
    }
    for(int i = 1; i < LOG; i++) mul(i - 1);
    for(int i = 0; i < sz; i++) dp[i] = NEG;
    dp[0] = c[0];
    ll cur = 0;
    for(int i = 1; i <= k; i++){
        go(e[i].t - cur - 1);
        step(e[i].x, e[i].y);
        cur = e[i].t;
    }
    go(T - cur);
    if(dp[0] == NEG) cout << -1;
    else cout << dp[0];
}
int main(){
    init();
    solve();
}
