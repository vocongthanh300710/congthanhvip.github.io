TRIP01 — Giải thích code C++

Phân tích chi tiết theo code: ma trận (max, +), luỹ thừa nhanh, và công thức đáp án.
Đồ thị có hướng Ma trận (max, +) Luỹ thừa nhanh O(N³ log T)

1. Ý tưởng cốt lõi

Đề cho T tới 10⁹ nên không thể mô phỏng từng bước. Nhưng N ≤ 250 → ta có thể dùng ma trận.

Chìa khoá: Mỗi bước đi trên đồ thị tương ứng một phép nhân ma trận trên nửa vành (max, +). Khi đó, hành trình T bước tương ứng với AT, tính được bằng luỹ thừa nhanh trong O(N³ log T).

Định nghĩa ma trận A

a[u][v] = c[v]   nếu có cung u → v
a[u][v] = -∞     nếu không có cung

Ý nghĩa: đang ở u, đi sang v, nhận thêm c[v].

Phép nhân (max, +)

(X ⊗ Y)[i][j] = max_k ( X[i][k] + Y[k][j] )

Công thức đáp án

ans = (A^T)[1][1] + c[1]

Vì a[u][v] chỉ cộng c[v] khi tới v, còn c[1] ban đầu (lúc t=0) chưa được cộng. Vậy cần + c[1] ở cuối.

2. Giải thích từng phần của code

2.1. Khai báo & hằng số

1#include <bits/stdc++.h>
2#define ll long long
3using namespace std;
4const int N = 252;
5const ll INF = 1e18;

Giải thích:

  • N = 252: kích thước tối đa của đỉnh + 2 (chừa biên), vì N ≤ 250.
  • INF = 1e18: đại diện cho +∞ (số rất lớn).
  • Trong bài, -INF đóng vai trò −∞ — nghĩa là "không có đường đi".
⚠️ Lưu ý quan trọng: Không dùng LLONG_MIN vì khi cộng -INF + c[v] sẽ bị tràn số. Dùng -1e18 an toàn hơn vì vẫn cộng được với vài số dương mà không bị overflow.

2.2. Biến toàn cục

int n, m;
ll t, c[N], a[N][N], b[N][N], d[N][N];
BiếnVai trò
n, m, tSố đỉnh, số cung, thời gian

b[i][j]Ma trận kết quả (ban đầu = ma trận đơn vị)
d[i][j]Ma trận tạm, dùng để tránh ghi đè khi nhân

2.3. Hàm nhân ma trận (max, +)

void mul(ll x[N][N], ll y[N][N], ll z[N][N]){
    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= n; j++){
            z[i][j] = -INF;
            for(int k = 1; k <= n; k++){
                if(x[i][k] != -INF && y[k][j] != -INF){
                    z[i][j] = max(z[i][j], x[i][k] + y[k][j]);
                }
            }
        }
    }
}
Ý nghĩa: Tính z = x ⊗ y trên nửa vành (max, +).
  • z[i][j] = -INF: khởi tạo "chưa có đường đi".
  • Vòng lặp k: thử mọi đỉnh trung gian, cập nhật giá trị lớn nhất.
  • Điều kiện if(x[i][k] != -INF && y[k][j] != -INF): chỉ cộng khi cả hai đều có đường, tránh -INF + số làm hỏng kết quả.

So sánh với nhân ma trận thường:

Nhân thườngNhân (max, +)
z[i][j] = Σ x[i][k] · y[k][j]z[i][j] = max_k (x[i][k] + y[k][j])
Phép + → phép ·Phép · → phép +
Phần tử 0 = +0Phần tử 0 = -∞
Phần tử 1 = 1Phần tử 1 = 0
